# Manuales de TjournalX

Las guías explican cómo usar los módulos desde la aplicación. Los PDF se pueden descargar desde GitHub y las guías en Markdown se pueden leer en el repositorio.

| Manual | Qué cubre | Formatos |
| --- | --- | --- |
| Playbook y setups | Define un setup, organiza sus checklists y revisa la evidencia de ejecución. | [PDF](playbook-y-setups.pdf) · [Markdown](../MANUAL_PLAYBOOK_SETUPS.md) |
| Prácticas de aprendizaje | Registra ejercicios, vincula evidencia, adjunta capturas y repite una práctica. | [PDF](practicas-de-aprendizaje.pdf) · [Markdown](../MANUAL_PRACTICAS_APRENDIZAJE.md) |
| Sesiones de backtesting | Planifica una prueba, vincula operaciones históricas y prácticas, documenta decisiones y exporta informes por versión. | [PDF](sesiones-de-backtesting.pdf) |
| Mundos operativos | Trabaja con Real, Demo y Backtesting y distingue las fechas de mercado de las jornadas de práctica. | [Markdown](../MANUAL_MUNDOS_OPERATIVOS.md) · [Anexo ilustrado](mundos-operativos-con-capturas.md) |
| Ruta de validación de estrategias | Evalúa la evidencia para avanzar de Hipótesis a Backtesting, Demo y Real. | [Markdown](../MANUAL_RUTA_VALIDACION_ESTRATEGIAS.md) |
| Fiscalidad e ISR | Gestiona el registro fiscal hondureño, la estimación de ISR, el borrador 102 y los avisos de reglas fiscales. | [PDF](fiscalidad-e-isr.pdf) |
